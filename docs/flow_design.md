# 产品业务流程

> 研究模块的详细业务设计以 [`research_design.md`](research_design.md) 为准。

## 核心页面分工

- **行情页**：发现市场、行业和公司，不直接加入研究。
- **公司详情页**：查看单个公司的行情、财务、估值、公告和基础资料；提供“加入研究”。
- **行业详情页**：查看单个行业的表现、产业结构、景气数据和重点公司；提供“加入研究”。
- **研究页**：组织已加入的公司、行业和用户资料，形成多对象研究集合并展示综合分析 Dashboard。

## 主流程

```text
行情发现
→ 公司 / 行业详情
→ 加入研究池
→ 后台整理资料和业务联系
→ 用户添加标签、加入更多对象、上传资料
→ 相同标签形成研究集合
→ 选择分析模板
→ 生成综合分析 Dashboard
→ 新资料驱动增量更新和下一版报告
```

## 关键规则

1. 公司和行业是后台长期维护的两个核心对象，但研究页不重复它们的单体详情。
2. 用户第一次加入公司或行业时，不要求预先创建话题或专题；对象先进入“未分组”。
3. 用户标签定义研究边界，相同标签下的公司、行业和资料构成研究集合。
4. 后台重点维护行业—公司、公司—公司的业务联系，并保留来源、时间和核实状态。
5. 用户上传的财报、会议纪要、研报、笔记和表格参与增量整理与综合分析。
6. Dashboard 只在用户选定标签集合并发起分析后生成；单个对象刚加入时先展示研究准备状态。
7. 宏观和热点不是独立研究对象，只在与当前集合相关时作为分析输入。
8. 产品不输出买卖建议、目标价或统一技术评分。
